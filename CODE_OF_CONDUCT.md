# Código de conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/), cujo texto completo vale como parte deste documento.

## Em resumo

Esperamos de todas as pessoas que participam (issues, pull requests, discussões):

- Respeito e linguagem acolhedora, sem ataques pessoais, assédio ou discriminação.
- Crítica ao trabalho, nunca à pessoa.
- Respeito à privacidade: não publique dados pessoais de ninguém, nem dados de clientes em prints e logs.

## Aplicação

Comportamentos fora destas regras podem levar à remoção de comentários, commits e issues, e ao bloqueio temporário ou permanente no projeto.

Relate casos para [contato@sinqfy.app](mailto:contato@sinqfy.app). Todo relato é tratado com sigilo.
