# Política de segurança

## Versões com suporte

Só a versão mais recente da branch `main` recebe correções de segurança.

## Como relatar uma falha

Não abra issue pública. Use uma destas opções:

- **GitHub:** aba Security do repositório, botão "Report a vulnerability" (relato privado).
- **E-mail:** [iegosweber@gmail.com](mailto:iegosweber@gmail.com), com o assunto `[segurança] Trackify`.

Inclua o que for possível: a rota ou o arquivo afetado, os passos para reproduzir e o impacto (por exemplo, leitura de dados de outro site ou de outra agência).

## O que esperar

- Resposta inicial em até 7 dias.
- Correção priorizada conforme a gravidade, com crédito no aviso se você quiser.
- Pedimos que não divulgue a falha antes da correção ou de 90 dias, o que vier primeiro.

## Fora do escopo

- Instalações com `LOGIN=off` acessadas por outra máquina: o modo é só para uso no próprio computador.
- Falhas em plataformas de terceiros (Meta, Hotmart, Kiwify, Eduzz, Cloudflare).
